# geoenhance-docs

Documentation site for [GeoEnhance-AI](https://github.com/Akash-design-prog/GeoEnhance-AI) (SIH26142) — architecture,
validation results, the live demo walkthrough, and the trust/uncertainty methodology. Built with
[Docusaurus](https://docusaurus.io/).

## Local development

```bash
npm ci
npm run start
```

## Build

```bash
npm run build
```

Static output goes to `build/`. Deployment to GitHub Pages runs automatically on push to `main` via
`.github/workflows/deploy.yml`.
